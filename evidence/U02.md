# U02 层索引重叠：同一层被连续缩放

来源：SpektraFilm 原始源码
核验方法：实际指令执行到中间状态

## 观察
双方都按排序后的首项、中项、末项选三层，再依次原地修改。当输入只有两层时，中层和慢层指向同一层，造成同一层连续除以 gamma 两次。

## 结果
200 组 / 1–5 层；centers、sigmas 最大绝对差 0

## 意义与范围
这是比正常输入效果相似更具体的边界行为：centers=[-1,1]、sigmas=[0.4,0.4]、gamma=2 时，双方得到 [-0.5,0.25] 和 [0.2,0.1]。
合成边界输入；尚未核查上架 profile 是否实际使用一层或两层。读取的是第三次缩放后的中间数组。与 U01 同属曲线变形函数，是额外的边界测试而非新的独立模块。

```
def _speed_layer_indices(centers_c):
    """Return (i_fast, i_mid, i_slow) by ascending center (grain-speed order)."""
    order = np.argsort(np.asarray(centers_c, dtype=float))
    n = len(order)
    return int(order[0]), int(order[n // 2]), int(order[-1])
```
