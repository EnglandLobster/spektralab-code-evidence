# U04 曝光补偿：忽略常数项的四阶曲面与 ±2 档限幅

来源：SpektraFilm 原始源码
核验方法：内联计算块执行

## 观察
保留 15 个系数位置但忽略 p0，使用相同顺序的 14 个非常数项；经 z/sqrt(1+(z/2)²) 限幅，最后取 exp2。测试把 p0 设置为大随机值，检验它确实不参与结果。

## 结果
1500 组；最大绝对差 1.998401444325282e-15

## 意义与范围
参数布局、项顺序、限幅和指数转换组合对应，可与光谱窗口证据合并评估。
执行首通道内联计算块，预先设置其寄存器输入；测试对象为该计算块，系数按 profile 格式排列。

### SpektraFilm 原文：四阶多项式
[reference-sources/upstream/src/spektrafilm/utils/spectral_upsampling.py，第 174–190 行](../reference-sources/upstream/src/spektrafilm/utils/spectral_upsampling.py)

```
def poly2d_deg4(tc: np.ndarray,
                params: np.ndarray,
                center_tc: tuple[float, float] = (0.0, 0.0),) -> np.ndarray:
    x = tc[..., 0] - center_tc[0]
    y = tc[..., 1] - center_tc[1]
    x2 = x * x
    y2 = y * y
    xy_term = x * y
    x3 = x2 * x
    y3 = y2 * y
    _, c1, c2, c3, c4, c5, c6, c7, c8, c9, c10, c11, c12, c13, c14 = params
    # note that we want center_tc to be zero correction -> not adding c0
    return (
        c1 * x + c2 * y + c3 * x2 + c4 * y2 + c5 * xy_term
        + c6 * x3 + c7 * y3 + c8 * (x2 * y) + c9 * (x * y2)
        + c10 * (x2 * x2) + c11 * (y2 * y2) + c12 * (x3 * y) + c13 * (x2 * y2) + c14 * (x * y3)
    )
```
