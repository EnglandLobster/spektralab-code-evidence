# U05 DIR 前密度反推：完整函数与双重取负

来源：SpektraFilm 原始源码
核验方法：完整函数及真实 helper 执行

## 观察
正片分支取 dmax−density，按 donor-row/receiver-column 矩阵计算抑制量，从 log_exposure 中减去后逐通道插值；正片在插值前后各取一次负号的步骤也保留。

## 结果
168 组 / 19296 个通道输出；最大绝对差 4.440892098500626e-16

## 意义与范围
实际 nanmax、插值 helper 和整个反推函数均执行；双重取负在通常有限输入线性插值中代数冗余，是额外的实现对应细节。
有限、单调曲线，正片/负片与多种长度。与 U08 的逐像素耦合剂校正属于不同阶段。

### SpektraFilm 原文：反推及双重取负
[reference-sources/upstream/src/spektrafilm/model/couplers.py，第 30–38 行](../reference-sources/upstream/src/spektrafilm/model/couplers.py)

```
    couplers_amount_curves = contract('jk, km->jm', density_curves_silver, dir_couplers_matrix)
    log_exposure_0 = log_exposure[:,None] - couplers_amount_curves
    density_curves_corrected = np.zeros_like(density_curves)
    for i in np.arange(3):
        if positive:
            density_curves_corrected[:,i] = -np.interp(log_exposure, log_exposure_0[:,i], -density_curves[:,i])
        else:
            density_curves_corrected[:,i] = np.interp(log_exposure, log_exposure_0[:,i], density_curves[:,i])
    return density_curves_corrected
```
