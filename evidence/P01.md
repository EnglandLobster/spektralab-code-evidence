# P01 安装包内说明文件：手机仓库自述同步自桌面提交

来源：SpektraLab iOS 1.0.1 App Store 安装包内的明文资源文件
核验方法：解压读取 + 哈希 + 与桌面仓库同名文件逐段比对

## 观察
安装包的 `EngineResources/PRODUCT_PROFILES_NOTICE.md` 是明文文件，解压即可读取，不涉及解密。它由桌面仓库的 `engine/resources_product/NOTICE.md` 改写而来：桌面文件中以 "In the macOS app" 开头的一段，在 iOS 文件中换成了两段，其中一段写明：

> **In this repository (the phone)**, synced from the desktop's `0bca29da` on 2026-10-09: the engine loads a profile from `<resources>/profiles/<stock>.json`, so `app/SpektraLab/tools/build_engine.sh` (and the bench's) copies these profiles into the app's `EngineResources/profiles/` beside spektrafilm's and this notice in as `PRODUCT_PROFILES_NOTICE.md`.

同一段还引用了 `engine/tests/bw_checks.py`、`engine/resources/` 和 `engine/tests/mobile_checks.py`。同目录的 `ENGINE-COMMIT.txt` 内容为 `998fd80 2026-10-22`。

## 结果
- 安装包 SHA-256：`8ead4398a1e4d350a87aa8e4be86dc02fc4106ae5e5a2883d6da12b2a23a6c00`（41,834,945 字节，2026-10-28 自 App Store 下载）。
- 说明文件：5,402 字节，SHA-256 `8fd2e065323948eddddaa5750b394a31baca995de599e64cea798d41a9078d18`，包内时间戳 2026-10-27 10:25:26。
- `0bca29da` 与 `998fd80` 在 JamesQiu2005/SpektraLab 和 JamesQiu2005/spektralab-engine 的全部分支和标签中均不存在（2026-11-11 17:19 UTC 克隆）。
- 安装包内 33 份 profile 中，28 份与桌面仓库 `fd891c6` 的 `engine/resources/profiles/` 逐字节相同；其余 5 份是说明文件所述的产品自有 profile。

## 意义与范围
说明文件是随安装包分发的文字，内容是开发方对手机仓库来源、目录和构建脚本的自述。它记录的是仓库之间的同步关系和目录结构，不是对 iOS 引擎每个函数来源的逐项核对；函数层面的对照见 U01–U08、D01–D03 和 [P02](P02.md)。
28 份 profile 随附 CC BY-SA 4.0 许可文件和署名，本项不把它们列为许可问题。
摘录只包含上述两段。完整文件不在本仓库中，可从安装包取得后按哈希核对。
