# U08 DIR 逐像素校正：上游结构对应、桌面数值对照

来源：SpektraFilm 结构 + 桌面版数值基线
核验方法：静态上游核对；执行基线是桌面源码

## 观察
正片 dmax−cmy、二次高曝光修正 c+=shift*c*c、donor-row/receiver-column 矩阵乘积，与原始 couplers.py 预扩散子计算对应；iOS AIR 与桌面 nodes.metal 也有逐项对应。

## 结果
与桌面函数比较：10000 组 / 90000 个通道输出；最大绝对差 0

## 意义与范围
验证了真实 AIR 计算，且原始 SpektraFilm 的相应子计算有直接源码定位。
10,000 组测试的预期值来自 SpektraLab 桌面源码，未在该测试中执行 Andrea 的 Python。未覆盖上游后续空间扩散和最终 log_raw 相减。

### 桌面原文：实际数值比较基线
[reference-sources/desktop/engine/src/shaders/nodes.metal，第 166–183 行](../reference-sources/desktop/engine/src/shaders/nodes.metal)

```
kernel void spk_couplers_correction(device const float* cmy [[buffer(0)]],
                                    device const float* m [[buffer(1)]],
                                    device const float* dmax [[buffer(2)]],
                                    device const uint* pos [[buffer(3)]],
                                    device const float* shift [[buffer(4)]],
                                    device const uint* n [[buffer(5)]],
                                    device float* out [[buffer(6)]],
                                    uint3 thread_position_in_grid [[thread_position_in_grid]]) {
    uint i = thread_position_in_grid.x;
    if (i >= n[0]) return;
    float c0 = cmy[3u * i], c1 = cmy[3u * i + 1u], c2 = cmy[3u * i + 2u];
    if (pos[0] != 0u) { c0 = dmax[0] - c0; c1 = dmax[1] - c1; c2 = dmax[2] - c2; }
    float sh = shift[0];
    c0 += sh * c0 * c0; c1 += sh * c1 * c1; c2 += sh * c2 * c2;
    out[3u * i]      = c0 * m[0] + c1 * m[3] + c2 * m[6];
    out[3u * i + 1u] = c0 * m[1] + c1 * m[4] + c2 * m[7];
    out[3u * i + 2u] = c0 * m[2] + c1 * m[5] + c2 * m[8];
}
```
