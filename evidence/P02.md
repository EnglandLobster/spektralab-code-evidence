# P02 桌面着色器内核名：42 个中 41 个在 iOS 库中同名

来源：SpektraLab 桌面工程；另含事后公开的 spektralab-engine 仓库
核验方法：函数名集合比对

## 观察
桌面仓库 `fd891c6` 的 `engine/src/shaders/` 下 8 个 `.metal` 文件共定义 42 个 kernel 函数。其中 41 个名称出现在 iOS 1.0.1 恢复出的 Metal 库中；未出现的一个是 `spk_highlight_headroom`。
开发方 2026-11-02 公开的 spektralab-engine 仓库（`1f6cad7`）在 `kernels/` 下 8 个 `.metal` 文件中定义 39 个 kernel 函数，其名称在 iOS 1.0.1 库中出现 0 个，在桌面 `fd891c6` 中出现 0 个。

## 结果
- iOS 1.0.1：58 个 AIR 模块，68 个函数，其中 58 个以 `spk_` 命名。
- 桌面 `fd891c6`：41 / 42 个 kernel 名在 iOS 库中同名。
- spektralab-engine `1f6cad7`：0 / 39。
- iOS 库中有 27 个函数名不在桌面 `fd891c6` 的 kernel 名单中。

## 意义与范围
本项只比较函数名。同名不等于函数体相同，41 不是代码复用比例。参数名和顺序的核对见 [D03](D03.md)，它覆盖其中 5 个 shader 文件的 34 个内核；函数体和数值结果的核对见 U01–U08。
iOS 库中另有 27 个函数不在该桌面版本的名单中，首页"已发现的差异"已记录移动端内核集合与所选桌面版本存在差异。
spektralab-engine 的结果说明的是该仓库与 1.0.1 库在命名上不对应；该仓库未标明对应哪个上架 build。

## 定位
桌面：`engine/src/shaders/{blur,contrast_mask,gamut,grain,nodes,overscan,scene_latitude,util}.metal` @ `fd891c6`
移动引擎仓库：`kernels/*.metal` @ `1f6cad7`
iOS：core-comparison/air-functions.json
