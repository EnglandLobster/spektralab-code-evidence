# U03 光谱窗口 logistic：整组稳定化阈值与分支

来源：SpektraFilm 原始源码
核验方法：完整子函数执行 + 常量读取

## 观察
共同采用 nu 下限 1e-5、指数截断 ±500、nu×log(2) 在 50 处分流，以及相应 log1p/expm1 稳定化公式。iOS 还按 t 的正负实现稳定的 logaddexp；上游在这一层调用 NumPy logaddexp。

## 结果
2028 组；最大绝对差 3.530509218307998e-14

## 意义与范围
关键是阈值和稳定化策略成组对应，且两类分支都已执行覆盖：nu×log(2)>50 / ≤50 为 141 / 1887 次；t>0 / ≤0 为 838 / 1190 次。
执行对象为 locked_logistic_rising 子函数；4 参数 erf、8 参数 logiflex 窗口及通道组合另有静态核对。

### SpektraFilm 原文：稳定化实现
[reference-sources/upstream/src/spektrafilm/utils/spectral_upsampling.py，第 201–212 行](../reference-sources/upstream/src/spektrafilm/utils/spectral_upsampling.py)

```
    nu = np.maximum(np.asarray(nu, dtype=float), 1e-5)
    S = 1.0 / (sigma * _SQRT2PI)
    k = (2.0 * nu * S) / (1.0 - 2.0 ** (-nu))
    exponent = np.clip(-k * (x - mu), -500.0, 500.0)
    nu_log2 = nu * np.log(2.0)
    log_q = np.where(
        nu_log2 > 50.0,
        nu_log2 + np.log1p(-np.exp(-nu_log2)),
        np.log(np.expm1(nu_log2)),
    )
    log_denom = np.logaddexp(0.0, log_q + exponent)
    return np.exp(-(1.0 / nu) * log_denom)
```
