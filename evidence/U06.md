# U06 曲线插值：首端点截断覆盖重复点右偏规则

来源：SpektraFilm 原始源码
核验方法：iOS AIR 与原始 Python 对照执行

## 观察
对横坐标 [0,0,1,2]、值 [10,20,30,40] 查询 0，iOS 与上游 fast_interp 都返回 10；同一上游文件的 NumPy 插值基线返回 20。内部重复点 [0,1,1,2] 查询 1 时三者都返回 30。

## 结果
140 组 / 8400 个通道输出；最大绝对差 4.192071023645383e-07；另含 2 个边界例子

## 意义与范围
共同选择是先处理首端点，再进行右偏二分查找，能用四个数字直接复核。
采样点数 4/8/17/65，有限、单调可重复坐标；AIR 编译到 Mac CPU，参考端为原始 Python 函数体；float32/FMA 与 float64 有数值精度差异。倒数差值输入按上游预计算规则提供。

```
            if x <= xa[0]:
                flat_result[i, c] = y_vals[0, c]
            elif x >= xa[K - 1]:
                flat_result[i, c] = y_vals[K - 1, c]
            else:
                idx = np.searchsorted(xa, x, side='right')
                low = idx - 1
                x0 = xa[low]
                # Use precomputed reciprocal to avoid division in inner loop.
                t = (x - x0) * inv_dx_val[low]

```
